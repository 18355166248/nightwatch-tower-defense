# 第三关通关方案与验证

日期：2026-10-08。使用真实战斗、寻路、经济与模拟时钟回放；不加钱，不跳过失败，不在战斗中自动补塔。不是完整浏览器手动游玩或真人胜率验收。

## 结果

- 同24种固定策略组合，旧版16种通关，新版20种通关；4种失败集中在整体过于靠入口且优先补塔的组合。
- 推荐构筑打完八波214名敌人，第一波漏1个，之后零漏，最终9/10生命。
- 30／60帧与1／2倍速四种组合均可胜。同策略与配置的战斗结果具有确定性。
- 开局180→200金币；前三波生命降低约8%；后五波、护甲、护盾、奖励与塔属性不变。第三关波间8→16秒，可提前开波。初次尝试建议1倍速。

## 复现与限制

`npm run verify` 执行规则回归；`node scripts/report-third-level-balance.cjs` 重建前后24场景对照、逐波漏怪、金币与购买记录，输出到 `validation/third-level-balance-2026-10-08.json`。

自动回放按合法顺序执行波间消费，没有模拟鼠标操作耗时。16秒准备窗为每波最多4项消费留出余量；真机触摸、完整浏览器手动八波和真人成功率尚未验收。少带克制塔、塔位偏离火力走廊或长期不消费仍可能失败。
