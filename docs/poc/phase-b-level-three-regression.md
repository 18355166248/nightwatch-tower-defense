# 首关三级塔与节奏候选复核 · 2026-09-26

## 本轮已接入

机枪塔、冷凝塔从 Lv1→Lv2→Lv3 都可使用同一个升级入口。Lv3 机枪：42 金、3.2 格、18 伤害、0.27 秒攻击间隔；Lv3 冷凝：48 金、3.5 格、8 伤害、0.48 秒攻击间隔、65% 减速 1.8 秒。塔等级规则集中在 `TowerLevelRules`，准备态撤销、检查点复原与回放累计投入都从同一个函数计算，不再只算第一次升级。程序绘制的塔在 Lv3 多一圈青色内环；不依赖新增贴图。

引导完成后的波间文字只提示“余钱可升关键塔至 Lv3”，不自动替玩家消费；第一波后的 Lv2 教学仍保持原样。当前波次与敌人数据**没有**因第三级开放而修改，因此原推荐回放仍是只升级一次的 123 敌、344 金投入基线。

## 验证

复现：`npm run verify`、`npm run build:web`、`node scripts/probe-first-level-pacing.cjs`。规则测试覆盖两塔 Lv3 扣费、满级、退款、检查点等级/金币恢复、等级对应属性及真实战斗伤害/减速。右侧浏览器在显式 `qa=1` 样例中暂停第 3 波，点选机枪依次支付 24/42 金；再点选显示“机枪塔 Lv3 · 3.2格 · 伤害18”和“已满级 · 当前 Lv3”，外环/内环可见，控制台无 error/warning。该 QA 操作验证的是升级交互与表现，不是正常首局胜率或完整通关。

## 未采用的节奏候选

节奏探针会克隆关卡配置，不会写回发布波次。候选只轻微增加第 3/4 波人数，后四波放大至原来的 2.2/2.8/3.2/4 倍并将间隔乘 1.15；将 Lv1 冷凝试作 7 伤害、0.5 秒间隔、55% 减速，并在第 5/6/7 波后试作额外升级。它确实把 1× 纯战斗模拟拉到约 338.7 秒，计入七次 8 秒自然倒计时约 394.7 秒（6 分 35 秒），刷怪期空场约 5 秒；但是 319 名敌人带来 1560 金结余，混合 466 金与纯机枪 432 金都满血零漏，同格纯机枪加一座塔 462 金仍满血。因此**局长达标不等于策略和经济达标，此候选不发布**。

当前正式配置仍是：混合 344 金、纯机枪 324 金同为零漏；混合 1× 理论局长含自然倒计时约 204.9 秒（3 分 25 秒）。下一步应优先建立至少两种有效塔位的等预算压力对照，再重调后期金币来源、可购买成长与威胁曲线。真人无口头指导整局、6–8 分钟胜利中位数和冷凝收益门槛均未通过；按当前要求不做 Android 真机测试。
