# 第一关入场与渐进教学浏览器回归 · 2026-09-26

目标：让默认入口拥有可交互的任务卡，并让首次布塔到开波有清晰、可跳过的步骤；不改变玩法门禁和 QA 夹具。

环境：Cocos Creator 3.8.8 Web Mobile 发布构建；右侧浏览器 `http://127.0.0.1:4176/?build=first-level-onboarding-final-0057`，视窗约 377×600。`npm run verify` 31/31 通过。Android/iOS 真机未测。

| 操作 | 结果 |
|---|---|
| 默认打开 | 夜城任务卡显示目标、机枪/冷凝分工与“开始布防”“直接开始”两种选择；未显示 QA 地图 |
| 任务卡期间点底部塔位 | 卡片仍在，金币和塔数不变；底层战场不能误触 |
| 点“开始布防” | 卡片关闭，“第 1 步”提示与机枪塔高亮出现 |
| 选机枪，点 `(4,3)` 预览并确认 | 高亮进入格子；路线 12→14，金币 120→90；确认后提示第二座塔 |
| 选冷凝，点 `(3,5)` 预览 | 文案正确显示“第 2 步”，高亮跟随实际预览格，不停在首次建议格 |
| 确认冷凝后点开始 | 金币 50，两塔、路径 14；“第 3 步”高亮开波按钮，第一波正常刷怪 |
| 战斗中点“跳过” | 教学高亮和跳过按钮消失，战斗不断；普通操作提示继续可见 |
| 首页点“直接开始” | 跳过教学进入可布塔战场；没有自动建塔或开波 |
| `?qa=1` | 直接进入原 QA 战场，三网格和夹具按钮可用，无任务卡 |
| 控制台 | 0 error、0 warning |

边界：这是第一版可操作教学，不等于真人首次理解率通过；不同屏幕比例、安全区、长局和真机还未验证。任务卡是入场层，之后的布塔、战斗、结算仍由既有系统拥有。
