# 第一关教学波间一键开波回归 · 2026-09-26

## 问题与改动

教学模式清场后已经无限时等待玩家补塔，但旧流程按 ▶ 只恢复 8 秒倒计时；若想立即迎敌，还需再点“提前开波”。这重复了一次确认，也把“继续”解释成“开始等待”。现在教学波间的 ▶ 直接开下一波，提示文案同步改为“开下一波”。

`BattleStateMachine.startNextWaveFromHeldIntermission()` 只接受“从倒计时暂停”的状态；自然倒计时、提前开波与教学继续共用 `beginNextWave()` 转换。自由模式与跳过引导仍按原 8 秒倒计时，普通战斗暂停仍恢复原阶段。未改敌人、塔、经济或波次配置。

## 证据

- `npm run verify`：50/50，通过教学一次继续、重复点击不二次推进、普通暂停保留阶段等规则测试。
- `npm run build:web`：Cocos Creator 3.8.8 Web Mobile 发布构建成功。首次沙盒启动 Creator 异常退出，获运行权限后同一构建命令成功；不是源码错误。
- 右侧浏览器 `http://127.0.0.1:4176/?build=guided-one-tap-1031`：默认教学四塔开局，第一波 6/6 清场、核心 10/10、金币 54；点击一次 ▶ 后立即显示“第 2 波：发条步兵×6进场”，画面有第二波敌人，未显示中间倒计时。控制台 0 error / 0 warning。

## 仍需真人验证

自动化和作者操作不能证明首次玩家理解补塔建议或新节奏是否更好；需要观察无口头指导玩家在波间的犹豫、误点和整局时长。本轮按用户要求不做 Android 真机测试。
