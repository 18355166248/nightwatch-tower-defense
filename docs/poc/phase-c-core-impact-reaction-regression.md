# 出口核心漏怪受击反应

日期：2026-09-27。基于上一轮独立世界核心候选图，只改善“敌人抵达后目标有没有反应”，不调整伤害、路径、波次和胜负门槛。

## 实现

- 沿用 `CombatFeedbackRuntime.coreHits` 的真实漏怪事件与 0.28 秒寿命，不另开 Tween 或依赖结算回调。独立纯函数 `CoreObjectiveReaction` 从剩余时间求挤压、轻微下沉与短促暖色闪动；多次漏怪只取最大强度，结束后严格回到初始缩放、位置和原色。
- `CoreObjectiveArtView` 只给目标切图应用姿态；原有健康圆环、左侧生命牌、漏怪红环和音效保留。没有全屏震动或玩法 hit-stop，避免挡住持续布塔/观察路线。
- 新资源加载失败时世界切图仍隐藏，原程序化目标仍可见；反馈函数不参与游戏状态机。

## 验证

- `npm run verify`：101/101。覆盖峰值、半程衰减、同时漏怪不叠加、结束复位及非法时间输入。
- Cocos Creator 3.8.8 Web Mobile 发布构建通过。右侧浏览器显式 `?qa=1`，用 `H` 加载核心 2/2 的短折线失败夹具，1× 运行到第二波失守：18 生成、16 击毁、2 漏、核心 0/2、局内 00:41；结算与返回按钮可见，浏览器无 error/warn。测试地址为 `http://127.0.0.1:4176/?qa=1&build=phase-c-core-impact-2239`。
- 另一次 1× 低频采样在约 40.38 秒局内时命中首个真实漏怪帧：`leakedEnemyCount=1`、`coreHealth=1/2`、`phase=clearing`、`activeFeedbackCount=1`；画面可见出口红暖冲击环、核心和刚抵达的敌人。先前过密轮询会干扰画布帧推进，已弃用该采样结果。**没有连续保存 0.28 秒内的变形序列**，因此无法从单帧判定挤压/复位的主观强度；这仍待人工动态观感复核。

## 仍缺

本构建尚未做普通入口 1× 八波完整复跑，也没有 5 名无指导首次玩家的目标识别与受击感知证据。正式美术、商业权利及用户要求以外的 Android 真机验证均未宣称通过。
