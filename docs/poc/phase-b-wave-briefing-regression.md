# Phase B 波间敌情预告分区（2026-09-27）

## 问题与改动

- 原波间引导把下一波敌情直接接在底部操作指令后，窄屏引导槽只能容纳两行，混编信息容易被裁切，也会抢走“下一步做什么”的位置。
- 现在波间顶栏固定显示两行：下一波真实编队的短名与数量、针对敌种的简短应对；底栏保留建塔、升级和继续操作。选中炮塔后升级按钮接管底栏，顶栏预告仍可见。
- 预告编队由波次配置按敌人 ID 聚合，同一份数据生成窄屏短名和辅助描述完整敌名；战斗期间恢复普通顶栏，未改变出怪、经济、伤害和波间状态机。
