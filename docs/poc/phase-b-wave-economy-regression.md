# Phase B 八波经济曲线与通关回归

> 执行时间：2026-09-07  
> 构建：Cocos Creator 3.8.8 Web Mobile 调试构建，`phase-b-wave-economy-final-1543`  
> 范围：第一关灰盒经济与八波闭环；不包含 Android 真机和真人平衡结论

## 目标与设计判断

上一批混合起手能稳定完成第一波，但部署后只剩 10 金，单靠 24 金击杀收益不足以在波间购买新塔。玩家做对了“冷凝前置 + 机枪输出”，却得不到即时成长反馈。

本批增加配置化清场奖励，使第一波结束后金币达到 54，可立刻选择一座机枪塔或冷凝塔。奖励不进入战斗运行时和状态机，而由独立结算器在清场边界发放。

八波清场奖励总计 196 金。第一波 8 人 / 0.60 秒和 6 杀 2 漏冻结值未修改。

## 代码边界

- `WaveDefinition.clearReward`：奖励与波次配置同源，新增波次无需修改结算分支。
- `WaveCatalog`：加载时拒绝负数、非整数奖励。
- `WaveRewardRuntime`：要求从第 1 波连续结算；重复结算返回 0，跳波直接报错。
- `NightwatchPocBootstrap`：只在状态机进入 `countdown` 或 `victory` 后协调清场、奖励和提示。
- `BrowserBattleDiagnostics`：发布累计清场奖励，便于浏览器核账。

重新部署会恢复开战前金币与塔位，并创建新的奖励运行时，因此不会把上局击杀或清场收益带回准备态。
