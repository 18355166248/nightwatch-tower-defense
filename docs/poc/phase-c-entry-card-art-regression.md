# 首关入场卡单位预览复核（2026-09-27）

## 本轮变更

普通入口原卡片以五行玩法说明为主，第一眼看不到机枪、冷凝和来袭敌人的实际形象。本轮复用项目已经入库的三张运行时 SpriteFrame，改成三张小型单位预览卡，文案压缩为关卡目标、改路和塔种分工。`FirstLevelIntroArtView` 只负责插画、异步加载和缺图时的卡片/名称兜底；`FirstLevelExperienceView` 仍负责入场状态及按钮高亮。没有修改战斗、教学门槛、经济或任何切图源文件。

## 验证

- `npm run verify`：99/99；`git diff --check` 通过。Cocos Creator 3.8.8 Web Mobile 发布构建完成。首次在受限命令环境运行编辑器得到 `exit null`，同命令在获准运行已安装编辑器后构建成功；这不是游戏代码编译失败。
- 右侧浏览器普通入口 `http://127.0.0.1:4176/?build=phase-c-entry-art-2051`：三张 SpriteFrame 实际显示，标题、三行目标说明、“开始布防”和“直接开始”均可见；控制台 0 error/warn。
- 点击“开始布防”后进入 140 金、12 格、第一塔高亮的渐进教学，入场插画已隐藏。没有使用 QA 模式；QA 专用三网格切换仍保留在 QA 入口，普通玩家入口并不会显示。
- 另以 360×780 浏览器视口复核：三图、完整三行说明、双入口都在卡片安全宽度内，点击主按钮仍进入第一步教学；检查后已恢复浏览器默认视口。

## 待复核

这是现有切图的展示复用，不是新正式首页设计稿或素材授权审批。默认视口与 360×780 的浏览器静帧仍不能替代更多手机比例、至少 5 名无指导首次玩家的理解率；不能把作者点击成功等同于玩家首局体验。按用户要求不做 Android 真机测试。引擎迁移仍由首关最终视觉和操作效果决定，而不是由此入场卡单项决定。
