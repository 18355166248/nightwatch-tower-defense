# 密集敌群冰环降噪回归

日期：2026-09-27。目标是解决第五至第八波冷凝群控时，多只敌人在同一小片区域各画完整冰环，青色线条叠在单位和动态道路上的视觉噪声。此项只改表现层，不修改减速、伤害、血量、索敌或路线。

## 实现边界

- `EnemySlowIndicatorSelection` 从只读敌人快照计算可画冰环的 ID：相距不足 0.8 格的减速单位只保留一圈，优先选择剩余减速时间较长者。零减速单位不占名额；相隔较远的敌人各保留提示。
- Sprite 层与资源加载失败时的 Graphics 灰盒层复用这一选择；每只敌人的冷色身体、血条和原有战斗状态仍逐只保留。选择器不改输入快照，也不参与战斗模拟。
- 不增加粒子、纹理或常驻 UI，不改变 `×N` 敌群徽标。冰环仍随减速到期消失。

## 验证

- `npm run verify`：92/92，新增测试覆盖密集、分散、未减速、单只与输入只读。`git diff --check` 通过；Cocos Creator 3.8.8 Web Mobile 发布构建完成。
- 右侧浏览器 `http://127.0.0.1:4176/?qa=1&build=phase-c-slow-ring-dedupe-1411`：用显式 QA 推荐布防，2× 实际推进至第七波。第五波 50/50、第六波 94/94，均 0 漏、核心 10/10。第六波同屏 3 名、第七波同屏 4 名减速时，截图可见密集群附近保留局部冰环和人数徽标，不再随同格人数画满圆圈；控制台 error/warn 为空。
- 已切回无 QA 参数的同构建玩家入口，首页与引导入口可见，右侧浏览器保留供评审。
