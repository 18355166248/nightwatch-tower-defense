# 首关路线异常保护与格心尾迹 review（2026-09-28）

## 本轮范围

沿用Cocos 3.8.8、默认双列交通、原波表/伤害/金币，继续落实原方案§10.3的无进度诊断与改路日志。不扩关、不迁移、不提交。game-ai用于保持寻路、局部队列与诊断分离；没有增加行为树、物理引擎或新寻路器。

## 可复用边界

- `RouteDiagnostics`是纯规则观察器：只读活动敌人、模拟时钟、地图版本与流场，不改位置、不重新BFS、不删敌人、不发奖励。
- 每个固定步前校验承诺路段/占格/可达/下一格/回头；步后在同一地图版本记录出生、格心交接、换列与正常离场。不能拖到下一帧输入改图后把旧迁移错标成新地图版本。
- 实际前进刷新无进度锚点；宽限`max(8秒, 3格/当前有效速度)`，微小位移累计，换列/改地图不刷新锚点。暂停不调用，页面墙钟不参与。
- 正常停等沿同列近邻追溯到正在前进的前排才豁免；假waiting、循环互等、孤立卡死不会被另一处运动永久掩盖。不是全地图无死锁证明，诊断是异常时安全退出的保护网。
- 默认纯测试策略抛`RouteDiagnosticError`并带地图版本、敌人from/to、前一格、3×3局部距离/下一格、近期事件；生产用`report`，一次故障锁存，不每帧刷屏。仅已知`RouteMovementError`走路线恢复，未知程序异常不吞掉。
- `PlacementModel`提供可选只读事务观察器，建造/出售/升级原子成功后才通知。被拒操作不记成成功，不逐帧靠塔数组猜操作；普通点击与QA真实购买都汇入同一路径。

## 日志不是完整输入录像

有界环形日志默认2048条，包含顺序、模拟时间、波次、地图版本和离散事件；旧事件淘汰数明确记录。保留尾迹涉及的占格版本，可重新建立真实BFS定位改路，不仅给最终地图。最新部署快照/错误上下文一并导出；重开、换网格、回首页清空旧故障与尾迹。

`data-phase-a-state`仅发布轻量故障码/事件数；`data-route-journal`在波结束、故障、重置发布只读快照，不每帧序列化整份日志。均留在本地，无外部上传。

尾迹不保证保留开局到终局所有输入，未包含全部数值配置和触控录像；不能称完整确定性录像回放。构筑回放和尾迹逐边复核脚本是不同证据。

## 异常恢复

共享`PauseOverlayRuntime`增加`route-error`来源，阻止继续/设置/后台解除绕过。生产界面显示“路线异常·已暂停”，只允许“重新部署”恢复战前检查点或“返回首页”。不判胜负、不静默删敌、不补发清场奖励。新局清理故障/日志后才允许开波。

显式`qa=1&qaRouteFault=1`地址，战斗中按K可让一步只读流场代理在已有敌人的承诺格返回无下一格；不改真实占格/金币。这个适配用于验证**同一生产诊断与恢复链**，不是自然出现的游戏故障，也不是浏览器里真的等待八秒复现无进度。普通入口及无开关QA按K无效果。
