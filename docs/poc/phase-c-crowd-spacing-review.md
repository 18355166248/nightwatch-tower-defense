# 密集敌人脚点避让 review（2026-09-28）

## 范围与实现

保留 Cocos Creator 3.8.8，不改地图、生成时序、敌人速度、索敌、伤害、奖励和任何平衡数值。
`EnemyCrowdLayout` 是无引擎的纯布局与可重置平滑模块；Sprite 视图只读取归一化偏移。
game-ai 技能用于分离路径和局部运动；本轮只做表现避让，不引入行为树、物理碰撞或新的寻路器。

- 原四槽偏移作为孤立敌人的静止目标；近邻才参与六轮对称分离，输入按出生序排序，不用逐帧随机数。
- 期望脚点间隔0.4格，最大偏移0.28格；脚点只能留在当前已承诺的两格走廊内，转弯不斜切第三格。
- 平滑依赖游戏时钟（90ms时间常数）；暂停冻结，重开清空，不另开 Tween/计时器。
- 阴影、减速环、血条和身体共用最终脚点；死亡读取最后脚点，短尸影结束后释放缓存。
- 发布只读 `nearCoincidentEnemyAnchorPairs`：小于0.1格的脚点对数。此值不是图像遮挡面积，也不是碰撞检测结果。
