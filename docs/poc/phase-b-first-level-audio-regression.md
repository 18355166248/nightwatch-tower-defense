# 第一关音效回归（2026-09-26）

## 范围与实现

- `FirstLevelSoundDirector` 只处理事件语义、最小播放间隔和静音状态；`BrowserSynthAudio` 实现浏览器 Web Audio。将来替换音频后端时，战斗模拟与界面事件无需依赖浏览器 API。
- `ui`、`sfx`、`alert` 三条总线分别设为 -8/-5/-3 dB，主总线 -12 dB；同时最多 12 个 oscillator 声部。没有循环背景音乐，也没有引用外部游戏音频。
- 首次触摸后才创建/解锁 AudioContext；页面隐藏时暂停，返回后下一次触摸尝试恢复。浏览器不支持或拒绝音频时静默降级，操作和战斗照常运行。静音是当前会话状态，刷新后恢复默认开启。
- 声音事件包括进入/跳过/选塔/按钮、成功布塔、拒绝布塔、机枪/冷凝攻击、击杀、核心受损、开波、清场及胜负。高频攻击和击杀按声音类别限频，避免同帧多塔造成密集叠音。

## 右侧浏览器手工回归

地址：`http://127.0.0.1:4176/?build=first-level-audio-0107`，390×844 竖屏。

1. 默认任务卡点击“开始布防”后，战场右上角显示“音效 开”；点击后变成“音效 关”，状态文案为“音效已关闭”；再点击变回“音效 开”，状态文案为“音效已开启”。
2. 选择机枪并建造，再选择冷凝并建造：金币 120→50，路径 12→14，教学进入开波步骤。
3. 点击开始第一波：8 名发条步兵入场；战斗继续运行，击杀回款出现，音效接入没有打断波次、索敌或经济状态。
4. 以上过程浏览器控制台 error/warning 均为 0。

## 证据边界

浏览器 UI 和规则测试不能替代人耳试听，当前**不宣称音色、响度、手机外放效果合格**。下一轮应由人实际试听，重点记录机枪连发是否刺耳、冷凝是否易区分、核心受损能否及时注意到，以及静音按钮是否足够醒目。本轮不做 Android 真机测试。
