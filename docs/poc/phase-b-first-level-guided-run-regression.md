# 第一关引导构筑与八波浏览器回归 · 2026-09-26

## 本轮要解决的真实问题

旧版默认仅 120 金，教学在两塔、路线 +2 就要求开波。右侧浏览器用该起手打到第二波失败：只击毁 2/16，核心归零。已验证的八波构筑实际需要 140 金四塔起手；旧教学与实战难度不一致。

第一次改为四塔开局后，第一波能清场，但只补一塔、随后任波次自动推进时，浏览器在累计 36 敌人处失败（23 杀、10 漏、核心 0/10），失败时仍有 132 金。主要缺口是波间没有给第一次玩的玩家足够的补塔时间和清晰指引，而不是经济收入不足。

## 现行方案

- 默认教学入口以 140 金起步；第一座机枪、第二座冷凝，再补两座机枪，参考高亮格横向形成四塔墙。高亮来自独立的 `FirstLevelOpening` 配置，实际布塔仍由现有预览与寻路规则决定。
- 教学模式每波清场后先结算奖励再暂停；可按提示补塔或自由调整，点 ▶ 恢复原 8 秒波间倒计时。“跳过引导”自动恢复倒计时；直接开始和 `?qa=1` 均沿用自动推进。
- 补塔建议从当前占格、金币和推荐次序推导，不自动放塔；推荐塔买不起或已建完时，允许自由布塔或继续。战斗状态机、经济账本与原始两塔开波门槛不因教学改变。

## 规则与浏览器结果

- `npm run verify`：33/33；新增测试证明四塔起手可由 140 金实际买下、路线 +4、第一波 6 杀 2 漏、清场后金币 54，且推荐位置可继续购买机枪。
- `npm run build:web`：Cocos Creator 3.8.8 Web Mobile 发布构建完成。
- 右侧浏览器地址：`http://127.0.0.1:4176/?build=first-level-guided-eight-0130`。按高亮位置逐次真实点击建造、2× 推进，第一波清场后停在金币 54 的补塔节点；第二波后金币 66、核心 6/10；第四波后金币 98、核心 6/10，提示切换为第二座冷凝；第五波后第二道横墙形成，路径 22 格。
- 第八波终局：`防线守住了`，击毁 86/90、漏怪 4、核心 6/10、金币 270；浏览器控制台 0 error / 0 warning。重新部署按钮可见。

## 证据边界与后续

这是按推荐提示执行的完整浏览器操作回归，不是新玩家样本。玩家自由构筑的难度、提示读懂率、音效听感和不同屏幕/设备表现仍需单独验收。本轮按用户要求不做 Android 真机测试。
