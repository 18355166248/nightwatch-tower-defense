# Phase B 固定步进与下排加固浏览器回归（2026-09-26）

## 触发问题

前一轮两次浏览器实战在相同推荐布防下，第三波清场回款分别为 64 与 68 金。新增完整八波回放在直接传入可变 `deltaSeconds` 时也复现差异：20 FPS 与 30 FPS 的第七、第八波击杀分布不同。原浏览器入口仅限制帧长并乘 1×/2×，仍把可变帧时长直接交给刷怪、移动、减速和开火逻辑。

## 修复边界

- `SimulationClock` 新增固定 1/60 秒步进累积器；每帧最多消费受 0.05 秒真实帧长及最高速度倍率约束的有限步数。长时间切后台后不会一次补跑整段战斗。
- 场景入口只在固定步进中推进战斗、波间倒计时和战斗反馈，渲染仍每帧执行；布塔改路的短提示继续按真实时间衰减。
- 重置地图、失败后重新部署清空累积余量，避免新局继承上一局不足一帧的模拟时间。攻击伤害、索敌、敌人属性、波次与经济数值未改。

## 规则与浏览器证据

- `npm run verify`：39 条规则测试通过。推荐 11 塔构筑在 20/30/60 FPS 输入和 2× 输入下，八波逐波击毁、漏怪、核心和塔数完全相同；最终为 80/86、核心 4/10。下排多补一座机枪的固定步进规则回放为 84/86、核心 8/10。
- `npm run build:web`：Cocos Creator 3.8.8 Web Mobile 发布构建通过。
- 右侧浏览器 `http://127.0.0.1:4176/?build=fixed-step-first-level-0338`：2× 速度按四塔开局与逐波推荐布防；第一、二波核心 10/10，第三波清场回款 64 金。第五波清场后在下排自选建一座机枪，共 12 塔，八波胜利结算 84/86 击毁、2 漏、核心 8/10、金币 292。浏览器 error/warn 日志为空。

## 证据边界

跨帧步进一致性是固定构筑与确定性输入的规则结果；浏览器只实测了一个完整 2× 加固单局，尚不证明所有设备、真实掉帧模式或真人操作都稳定。正式玩家理解度与难度仍需试玩。当前用户明确不要求 Android 真机测试。
