# 临时 HUD 文字生命周期与真实试玩回归

2026-09-28，Cocos Creator 3.8.8 发布构建12:49:04；继续现有框架，不做迁移或Android真机。

## 范围与实现

此前 HUD 即使隐藏，也会更新波次、波间阵容/策略、引导、小字帮助、升级和出售标签；没有点选塔时还会构造 `undefined` 升级/出售文案。仅 `node.active=false` 不释放独立TTF纹理。

新增 `VisibleHudLabel`，复用无引擎的 `VisibleViewResource`。临时标签首次可见才创建；隐藏时移出父节点并走正常Node销毁；再次显示按原工厂重建。布局函数独立缓存，新标签在可见前继承当前窄屏尺寸，资源异步到达时仍由原布局失效机制重排。对不存在的标签不写文本；未点选塔不构造升级/出售文案。

七项临时标签都有语义节点名，测量中可明确区分 `WaveBanner`、`BattleGuidance`、`TowerUpgrade` 等；不再把这些标签误认为结算页文字。常驻HUD、资源图标、结算内容及战斗/输入状态机不重写；字号、颜色、几何和原可见条件保持不变，不销毁共享图片或直接操作引擎纹理。
