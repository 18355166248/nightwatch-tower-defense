# 第一关疾行机与切图辨识回归（2026-09-26）

## 目标与边界

只在第一关增加一个会改变冷凝塔价值的敌人变体，不新增关卡、塔种或敌人 AI 状态机。第一、二波原封不动，第三波先 8 名步兵后 2 名疾行机，第四至八波递增；总数保持 90。疾行机与步兵同为 85 生命、击杀 4 金币，移速由 1 提至 1.6 格/秒；被冷凝减速后为 0.88 格/秒。多分组沿用原生成器的组间 1.5 秒间隔。

## 素材与浏览器发现

- 原创疾行机源图使用步兵源图作风格参考，经 OpenAI 内置 image_gen 生成；PNG 1254×1254、透明。用 `sips -Z 128` 缩为运行时 128×128、约 14 KiB。透明度和尺寸由 `asset_report.py` 验证；两敌人对照图见 `art-source/first-level-enemy-variants-contact.png`。
- 首次 Web Mobile 构建虽成功，新图却被 Cocos 默认识别为 `texture`，缺少 `/spriteFrame` 路径；浏览器实测所有单位图都退回 Graphics 彩色圆形。已修 `.png.meta` 为 `sprite-frame` 并重建，发布包资源目录出现 `level-one/units/clockwork-runner/spriteFrame`。新增规则测试固定四张单位图的导入契约。
- 修复后右侧浏览器确认塔、步兵和疾行机均显示为图片；疾行机是后掠铜鳍、青蓝眼缝/脚部涡轮的细长剪影。战场塔图原为 108 设计单位、大于约 72 的格宽，横墙互相遮挡；现限制为格宽 90% 且上限 82，商店图标仍 86。浏览器 375×600 截图中横墙已分格可辨。
