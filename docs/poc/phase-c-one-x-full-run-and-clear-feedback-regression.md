## 发现与修复：教学波间最后一击的残影

- 修复前第 5、6、7 波的清场暂停状态均出现过：诊断属性为 `phase=paused`、`activeEnemyCount=0`，但画面路径上仍留着重装敌人的死亡帧。它是反馈动画残影，不是仍存活的敌人。
- 根因：`NightwatchPocBootstrap.advanceGameStep` 在战斗暂停时直接返回，最后一击产生的死亡反馈也不再 `advance`，于是无限停留在画面。现在 `CombatFeedbackRuntime.shouldAdvanceFeedbackWhileGuidedHold` 只允许“教学波间暂挂且没有暂停菜单”时用真实帧时间推进短视觉反馈；战斗时钟、生成、资源与经济仍停住。手动暂停菜单依旧冻结反馈。策略和播放分别留在反馈模块与场景编排层，未把教学规则写进伤害/经济模型。
- `npm run verify` 通过 TypeScript 检查和 91 项规则测试；新测试覆盖重装死亡帧在 0.53s 后消失、较长金币跳字继续收尾，以及手动暂停不进入此分支。Web Mobile 发布构建通过。
