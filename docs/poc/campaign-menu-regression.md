# 欢迎页与夜城战役地图

2026-10-07。启动 → 欢迎页 → 开始游戏 → 关卡地图 → 点选据点 → 进入关卡。第一关继续启用新手引导，第二关自由布防；战斗与关卡数值未调整。

欢迎页沿用正式夜城插画，独立展示标题、玩法介绍、开始按钮与设置入口。地图由夜间街区、窗灯、河道、桥梁和据点路线构成，选中据点显示地区、说明、难度、波数与该关独立的最佳记录。未通关显示尚未通关，不伪造进度；现有两关均可选择。远方街区仅是背景说明，没有虚假的可点关卡。

## 扩展关卡

在 assets/scripts/config/LevelCatalog.ts 的 LEVEL_DATA 按显示顺序增加一项，提供 id、label、title、gridId、startingGold、waves 和 campaign（district、briefing、difficulty、guided）。LevelId 自动由目录键推导，无需在菜单增加编号分支。nextLevel 可选，指向下一关。地图按每页三关生成据点和翻页按钮，记录仍按关卡 id 隔离。

## 返回与资源

地图的返回按钮回到欢迎页；设置关闭后回到打开设置时的菜单。战前右上角提供返回地图入口：无塔直接返回，有塔先确认，取消保留塔位、金币和关卡教学状态；结束本局后重建战斗并在地图保留当前关卡选中。战斗暂停和结算的退出落点改为地图，文字保持一致。

战场引导与菜单视图分离。菜单隐藏时释放文字节点，欢迎插画使用原有可见资源租约，异步完成只能重绘最新状态，不可重新覆盖已经进入的战场。菜单图形只在状态变化时重绘。

# 局内顶部控制优化

建塔浮层间距：面板距离落点预留一个完整相邻行和额外间隔，上下空间不足时自动换侧。测试遍历九列棋盘全格与两种视口宽度，确认上下相邻整格都不落入面板热区。实际浏览器连续点击第 7 列第 8 行、上一行、下一行，浮层落点随点击切换，无需先关闭。截图：`build-menu-adjacent-row-gap.jpg`。291 项测试、游戏脚本类型检查及发布构建通过。

建塔浮层跨波次：新波次开始时只清理拖拽和候选路线，保留点格打开的选塔浮层。每帧重读可建状态，点选时重新校验敌人占格、金币和路线。实际浏览器验证第一波自动切入第二波后第 7 列第 8 行选塔浮层仍显示，两种塔可建，点选机枪成功（机枪从 3 座增到 4 座）。截图：`build-menu-across-wave.jpg`。291 项测试、游戏脚本类型检查和发布构建通过。

布防阶段的地图入口改用原有 HUD 铜框按钮，返回图标与文字分两行显示，不再由战役菜单额外绘制浮层。右上角共用一个控制槽，开战后切换为暂停；战斗中的返回地图仍从暂停菜单进入。

291 项测试、游戏脚本严格类型检查与 Web Mobile 发布构建通过。339 × 597 浏览器预览确认地图按钮正常返回选关，重新布防并开第一波后图标切换为暂停，点击正常打开暂停菜单。
