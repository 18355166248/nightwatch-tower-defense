# 首关敌人入场与贴地识别层回归（2026-09-27）

## 体验问题与改动

在右侧浏览器约 350×600 的当前首关中，推荐四塔首波已能把敌人引到中段，但普通小怪的铜色立绘容易融入灰石道路，出生也缺少由入口机械舱口进入战场的短反馈。原有伤害、减速、死亡特效不能承担常态辨识。

- `EnemyArrivalPresentation` 只按敌人首次出现在只读快照时的局内时钟计算 0.24 秒入场姿态；缩放 0.82→1、透明度 145→255、入口短环消退。暂停不走时钟，2× 随战斗缩短，减弱动态直接显示最终姿态。
- `EnemyGroundingView` 在立绘下独立绘制低亮接触斑与一条类型色标：步兵暖红、疾行青、重装铜金。它不跟随身体步伐弹跳，不遮盖路线箭头、血条或冷凝圈；敌人离场即释放对应节点与时间戳。
- 表现层没有写入 `WaveCombatRuntime`、路径、索敌、伤害、金币或碰撞。`PhaseBUnitSpriteView` 负责装配与节点生命周期，纯计算与绘制拆开，后续更换正式材质可单独替换贴地层。

## 验证

- `npm run verify` 105/105；新增规则测试检查暂停重绘、入场收束、减弱动态、离场重入、重开时钟倒退，以及三类接触斑不会超过单位尺寸。Cocos Creator 3.8.8 Web Mobile 构建通过，`git diff --check` 通过。
- 右侧浏览器 `?qa=1&build=phase-c-arrival-grounding-2350`：推荐四塔 16 格路线，1× 首波 9/9 击毁、核心 10/10、54 金；中段敌人、冷凝圈和道路箭头共存，控制台 0 error/warning。
- 后段密集波使用同一构建 `?qa=1&qaNaturalCountdown=1&build=phase-c-arrival-dense-2355` 的自动推荐布防进行观察：第八波多个 `×2/×4` 敌群徽标、道路箭头与炮塔仍可见，接触斑未变成一片亮斑；最终 212/213 击毁、漏 1、核心 9/10、07:50、10 塔、4 次升级，控制台 0 error/warning。它只验证候选视觉拥挤度和运行稳定性，不属于普通玩家玩法证明。

## 边界

贴地色标在手机宽度下仍较克制，是否真正提升三类敌人的辨识率必须让首次玩家看动态画面回答，静帧和自动测试不能证明。当前没有逐帧录屏证明 0.24 秒入场动效主观顺滑，也未完成正式美术/商业权利、普通入口本构建完整八波及 5 名无指导首次玩家验收。按用户要求不做 Android 真机测试，不据此宣布首关完成或决定迁移引擎。
