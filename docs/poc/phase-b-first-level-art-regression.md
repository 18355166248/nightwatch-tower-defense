# 第一关视觉样板浏览器回归 · 2026-09-25

目标：确认新增底图资源不挡输入，首关默认界面可读，并证明它是运行中可交互关卡。

环境：Cocos Creator 3.8.8 Web Mobile 发布构建，右侧内嵌浏览器 `http://127.0.0.1:4176/?build=first-level-art-2352`。当前浏览器视窗约 377×600；Android/iOS 真机未测。

| 操作 | 观察结果 |
|---|---|
| 打开默认入口 | 夜城底图显示；不出现三张测试网格和样例按钮；关卡引导、动态路径箭头和两塔按钮可见 |
| 选机枪，点路线格预览 | 绿色候选塔位、实际射程圈、改路路径显示；路径从 12 预览为 14 格 |
| 再点同一格 | 机枪塔落地，金币 120→90；引导提示再建一塔 |
| 选冷凝，预览并落塔 | 冷凝塔落地，金币 90→50；总计 2 塔，路径保持 14 格 |
| 点击开始 | 状态进入 spawning，第 1 波敌人出现，核心 10/10 |
| 控制台 | 0 error、0 warning |

资源导入备注：新 JPEG 最初被 Creator 导为普通 Texture，浏览器只见程序化画面；将 `backdrop.jpg.meta` 的 `userData.type` 改为 `sprite-frame` 并重新构建后，`level-one/backdrop/spriteFrame` 进入资源包，底图实机可见。

局限：当前塔、敌人和 HUD 仍是灰盒；没有首玩玩家测试，也没有以该样板跑完八波。本轮浏览器结果证明“资源可加载且玩法可继续”，不证明最终美术品质或游戏平衡。
