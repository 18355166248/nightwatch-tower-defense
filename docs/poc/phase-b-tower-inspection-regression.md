# 第一关已建塔射程检查回归 · 2026-09-26

## 目标与边界

原版本布塔预览已有射程圈，但已建塔在准备态点一下就直接撤销；玩家无法检查两塔覆盖范围，也可能误删。本轮只改变已建塔的输入与提示，不修改 `RIVET_GUN`、`FROST_COIL`、攻击结算、流场或开波门槛。

`TowerInspection` 管理纯输入状态；`NightwatchPocBootstrap` 仍是出售与 UI 事件编排者；`PhaseBCanvasRenderer` 根据只读快照绘制已有塔和预览的共用射程圈。游戏内塔属性提示在检查期间持续占用底部提示位，避免战斗事件覆盖顶部状态文案后信息立即消失。

- `npm run verify`：34/34 通过，新增测试覆盖第一次点击、切换查看目标、准备态二次确认撤销、战斗中关闭查看、状态清理。
- `npm run build:web`：Cocos Creator 3.8.8 Web Mobile 发布构建完成；`git diff --check` 通过。
