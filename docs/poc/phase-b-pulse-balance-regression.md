# Phase B 冷凝脉冲与后四波节奏回归（2026-09-26）

## 改动与口径

- 保留两塔、三敌、八波和前四波教学节奏；后四波提高重甲生命和同屏压力，降低疾行/重甲单体赏金。
- 冷凝只伤主目标，对命中点附近存活敌人施加短时减速；重复命中取更强效果并刷新时长，不叠乘。Lv1/2/3 脉冲半径为 1.5/1.7/1.9 格，可视环使用同一规则半径。
- 推荐升级安排在第 1/5/6/7 波清场后；提示只针对已建成且付得起的塔，不替玩家自动升级。
- 规则回放用 30 FPS 固定推荐操作；1×“局长”按第一波开始至胜利计。自由模式七段自然 8 秒倒计时合计 56 秒；教学模式是主动继续，不能把 56 秒强加到真实玩家时长中。玩家思考、早开波、暂停与后台时间没有从规则回放推断。

## 尚未通过的门槛

- 这是确定性规则回放，不是“无指导首次玩家”数据；至少 5 人灰盒首局、理解率、胜利中位局长和真实购买行为仍待测。
- 576 金终局结余偏高，玩家可能在后段大幅追加塔位、缩短战斗；目前不能认定经济已平衡。纯机枪对照也是“近等预算”，并非严格逐波同额现金流或原方案的无迷宫/免费塔等值对照。
- 213 只敌人的性能峰值、多个视口及真实用户对密集波次的疲劳感仍待验证；按用户要求暂不做 Android 真机。
