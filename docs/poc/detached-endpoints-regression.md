# 棋盘外出入口回归

正式第一、第二关已使用 9 × 13 棋盘，中央第 5 列的格心与横向中轴重合。入口、主通道和出口笔直相接，首尾不再产生横向接驳。教学塔位整体右移两格，首关推荐构筑八波回放结果保持一致；第二关高级回放调整末段左路补塔，仍能以 5 点核心生命通关。

入口和核心移到棋盘上下边界外，沿棋盘横向中轴居中；两端接入棋盘的道路笔直，不使用斜向连接。偶数列棋盘在首尾格内正交衔接逻辑格心。建塔改变路线时，转弯发生在棋盘内，沿直角道路移动。

道路、怪物、核心生命环和战斗反馈共用出入口投影。棋盘显示高度预留两端空间，逻辑格数、寻路距离、波次时序和伤害规则保持原有行为。

验证结果：

- 291 项自动测试通过，覆盖不同棋盘尺寸、外部端点不可建塔、原有格子点击坐标、正交路径与连续进出场位置。
- Web Mobile 构建通过，游戏脚本范围的严格类型检查通过，差异格式检查通过。
- 在 339 × 597 浏览器预览检查空场直线路径、入口附近建塔后的直角改道，以及第一波怪物实际进场。
- 未进行完整八波浏览器通关或手机人工验收。
