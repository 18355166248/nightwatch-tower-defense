# 首关音效事件与声部优先级候选（2026-09-28）

## 体验缺口

旧实现把升级、出售当成普通 UI 点击，三类敌人死亡也共用一个提示音；音高按每条振荡器全局轮换，使胜利和弦也可能偏移。12 声部满时按音符逐个截断，没有保证核心警报、胜败提示优先。暂停中的 AudioContext 仍允许排入音源，恢复时可能补播旧声。

本轮只补第一关已有动作的听觉语义与混音安全，不增加玩法，不把程序合成候选当作正式音频。

## 分层实现

- `FirstLevelSoundRecipes`：统一管理交互、两塔发射/命中、三类死亡、核心受击/危急、开波/清场/胜败的音色。两类发射各有三种整组音高/音量微变，UI/旋律不再被全局随机序列改调。所有音色为源码程序合成，无第三方采样。
- `FirstLevelCombatSound`：只读战斗事件；单帧同塔种不叠响，多死亡优先选重装，再疾行、步兵；核心从 3 以上降至 1–3 时才发一次危急意图，直接失败不再叠加危急。
- `FirstLevelSoundDirector`：每 cue 限频，三类死亡另共享 220 ms 总节奏；输出层拒绝时不占下次限频窗口。只读计数用于浏览器诊断，不影响伤害和时钟。
- `AudioVoiceBudget`：按整条音色事务预留最多 12 声部。警报高于普通 SFX，胜败高于警报；不足时只替换更低优先级组，同级不抢，空间不足则完全拒绝而不截和弦。抢占有 12 ms 退场淡出尾音，诊断计数是预留声部，不是瞬间所有 Web Audio 节点数。
- `BrowserSynthAudio`：未解锁、暂停或静音时不创建待播放音源；暂停/静音丢弃旧短音，恢复只收新事件，异常输出静默回退。Master/UI/SFX/Alert 保留原分贝余量；尚无 Music 总线或 BGM。

## 本地试听材料

```sh
npm run verify
node scripts/render-first-level-sound-review.cjs
```

输出 `art-source/first-level-audio/sfx-review-v1.wav` 与同名 manifest。当前为 48 kHz/16-bit/单声道、17.172 秒、1,648,556 B，单独音色排列样张峰值 -28.237 dBFS；不做归一化，不加入游戏包。manifest 提供每条 cue 的时间与变体索引及源代码说明。

这是数学振荡器的离线近似，不是浏览器系统输出录音，不能证明密集战斗响度或没有削波。需要用耳机/扬声器在游戏内判断：金属是否刺耳、三类死亡是否可区分、重要警报是否可闻、暂停恢复是否无尾音；本轮没有把这些主观项标为通过。
