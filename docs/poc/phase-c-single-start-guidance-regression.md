# 第一关单一开波入口与引导区：右侧浏览器回归

日期：2026-09-27。目标是减少首局操作歧义：底栏“开始第一波 / 开始下一波”是唯一开波主入口；中央行只保留重置、引导语，以及战斗中才出现的暂停键。本次不调整开波门槛、敌人和经济数值。

- 实现边界：`FirstLevelControlPolicy` 统一判断中央暂停键的可见与可点击状态，避免隐藏后留下热区；`PhaseBLayout` 统一中央按键与引导文本的安全宽度；`PhaseBHudView` 管文字，`PhaseBCanvasRenderer` 管底框和图形，`NightwatchPocBootstrap` 只做输入分发。首局教学焦点移到底栏开波键。
- 自动化：`npm run verify` 通过 89 项规则测试，包含准备、战斗、暂停、教学待命的控制策略和 360×780 / 390×844 / 430×932 布局约束。Cocos Creator 3.8.8 Web Mobile 发布构建通过；`git diff --check` 通过。
- 右侧浏览器：发布包 `http://127.0.0.1:4176/?build=phase-c-single-start-guidance-1248`。入场后中央没有第二个开波键；点击原中央开波位置没有启动波次。手动放置推荐的 3 座机枪和 1 座冷凝塔后，底栏主按钮变为可用并启动第 1 波。战斗中中央出现暂停键；暂停菜单“继续”可回到第 1 波。第 1 波 10/10 核心清场后，经底栏启动第 2 波；第 2 波也以 10/10 核心清场并进入第 3 波待命。观察到第三波待命时 96 金、路线 16 格。浏览器 error/warn 均为空。
- 窄屏：临时切到 360×780，画布实测 360×780、无页面纵向溢出；中央重置与两行引导语、底栏塔卡和开波键完整可见。临时视口已恢复默认，右侧浏览器保留最终发布页供复核。
- 未验证：本次没有重新打完八波；没有无指导新玩家对“唯一开波入口”的理解率与误触统计，也没有完整正式切图及音效体验验收。按当前要求不做 Android 真机测试。本次浏览器结果只支持继续在 Cocos 中打磨，不作为 Phase B / Phase C 通过或否定 Godot 迁移的证据。
