# 首关重装敌人与八波混编回归 · 2026-09-26

## 范围与复现

第五波先单独展示原创重装敌人「铁罐搬运者」，第六至八波再与现有两种敌人混编。敌人仍走统一流场、减速、奖励与核心扣血链路；新增图片通过同一 SpriteFrame 资源层加载，缺图时使用程序方形轮廓。波前预告从配置统计敌人，开波顶栏只显示先头单位，避免完整混编文案压到资源卡。首波回款后的推荐升级从配置取机枪塔位置和价格，规则回放也执行同一步骤。

复现：`npm run verify`、`npm run build:web`、`node scripts/compare-first-level-strategies.cjs`。规则回放用固定 60 Hz、140 金四塔开局、第一波后升级初始机枪、每波后按推荐顺序补塔；秒数仅指模拟战斗，不含玩家思考或教学停留。图片来源、原图、128×128 RGBA 运行时图和待审批字段见 `docs/first-level-art.md` 及 `art-source/first-level-units/iron-canister-hauler-manifest.json`。

升级已成为当前推荐路径的有效决策，铁罐初见和后续混编的工程链路也成立；但纯机枪更便宜且同样零漏，不能推断冷凝塔具有等预算策略价值。首关仍未达到方案中的 1×、6–8 分钟目标，末段余钱 562 暗示后期缺少足够有意义的消费/布塔压力。接下来要用等预算的两套以上布局、真人首次试玩和实际耗时复核，再调塔定位与局长；不能靠组间空等或单纯堆血量凑时长。重装切图仍是候选，正式动作、密集混编辨识、音效主观体验和 Android 真机均未验收；本阶段按用户要求不做 Android 真机测试。
