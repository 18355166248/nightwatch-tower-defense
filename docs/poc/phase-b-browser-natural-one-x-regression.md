# Phase B Web Mobile 1× 自然波间八波实跑（2026-09-27）

## 口径与入口

- Web Mobile 发布构建，右侧浏览器 `?qa=1&qaNaturalCountdown=1`，默认 1280×720 浏览器视口中的竖屏游戏画布。
- `A` 只在开局通过真实建造事务布置推荐四塔，`Space` 只启动第一波。其后不按提前开波、不切 2×、不再手动控制战斗。
- 这个 QA 模式在每波清场奖励结算后调用原有 `applyGuidedQaPurchases`，以真实账本扣费/升级/建塔；不暂停自然波间 8 秒倒计时。自动购买只是消除远程浏览器操作延迟，不是玩家模式的自动玩法。
- 玩家默认入口、教学停波和手动购买规则均未改动。第一次仅手动按 `B` 的试跑因截图到按键超过剩余 2 秒、错过第一波补塔窗口而作废，不计为标准构筑证据。

## 判断与剩余门槛

- 实际 Web Mobile 1× 引擎局长与规则回放的约 414.7 秒一致，标准推荐构筑在自然倒计时下可完整零漏守住八波；这补上此前只有 2×/提前续波的浏览器工程缺口。
- 画面观察：上排仍是主要交火区域，第七八波的下路折返和冷凝脉冲可见；密集敌群更多依赖 `×N` 合并徽标辨数。该观察是作者视觉检查，不替代首次玩家理解率。
- **不能据此宣称 Phase B 的“胜利中位局长 6–8 分钟”已达标**：只有一局 QA 推荐构筑、自动购买、无玩家决策时间；提前开波和不同构筑仍可能缩短局长。至少 5 名新的无指导首次玩家及其原始时间记录仍缺。当前只在右侧浏览器验证，不做 Android 真机测试。
