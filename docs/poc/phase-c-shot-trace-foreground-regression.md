# 首关炮弹轨迹与前景层复核（2026-09-27）

## 目标与边界

前一轮把炮塔开火、命中反馈从主画布抽离，但机枪和冷凝仍主要依靠颜色区分：都像一条射向目标的完整光线。单位 Sprite 又盖在同一 Graphics 层之上，短暂火花容易被遮挡。本轮只改表现，不触碰伤害、索敌、寻路、经济、暂停或结算判定。

- 机枪：将完整射线改为沿原射线方向行进的短暖色弹痕和前端弹丸；寿命由 0.10 延长到 0.16 游戏秒，2× 时仍约 0.08 现实秒。`ShotTraceGeometry` 是纯几何函数，限制尾长、透明度和零距离异常输入。
- 冷凝：保留持续很短的细青色双层束线，以形态而不只靠颜色区分塔种。
- `CombatFeedbackView` 分为单位后方的减速/死亡/核心反馈与单位前方的弹痕/命中/奖励；`CombatForegroundView` 负责独立前景 Graphics，放在单位 Sprite 之后、HUD 之前。结算状态清空前景，避免粒子盖住结果。
