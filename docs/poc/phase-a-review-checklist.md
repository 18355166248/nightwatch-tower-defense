# Phase A 交叉评审清单

评审目标：判断《夜城防线》的“自由摆塔造迷宫”是否值得进入第一关完整制作。不要在本次评审中扩塔、敌人、关卡或外围系统。

## 1. 规则与代码评审

- [ ] 非法封路是否保持金币、占格、地图版本和流场全部不变。
- [ ] 活动敌人的 `fromCell` 与 `toCell` 是否都禁止落塔。
- [ ] 新路线是否从承诺格继续，且不会把敌人送回 `fromCell`。
- [ ] 等长最短路是否先保持朝向，再使用固定方向序，保证回放确定性。
- [ ] 陈旧预览是否被版本号拒绝，快速操作是否可能重复扣费。
- [ ] `TOUCH_CANCEL`、画布外松手、页面隐藏是否清除预览且不扣费。

复现命令：

```bash
npm run verify
npm run poc:automated
```

期望：7/7 测试通过；100 次回放的 `backtrackCount`、`stuckCount`、`atomicViolationCount` 都为 0。

## 2. 浏览器体验评审

- [ ] 三种网格均可切换，切换后金币、塔、敌人与地图版本被完整重置。
- [ ] 短折线显示 16/17/16 格；长蛇形显示 22/25/22 格。
- [ ] 拖拽和“点塔—点格预览—同格二次确认”都能完成建造。
- [ ] 合法预览为绿色、非法预览为红色，并给出具体拒绝原因。
- [ ] 准备态点击已有塔全额撤销；运行态不得出售。
- [ ] 运行中建塔后敌人不中断、不回头、不穿塔。
- [ ] 控制台无 error/warning。

已知问题：按钮已改为矢量符号，但在 390×844 内嵌浏览器中仍偏小；性能统计层覆盖左下区域。两项完成可读性复验前不要启动首次玩家测试。

## 3. 真机门禁

- [ ] iPhone 12 Safari 完成固定分母测试。
- [ ] Redmi Note 11 Chrome 完成固定分母测试。
- [ ] 每个“网格×设备×输入方式”独立满足合法提交 ≥99%、落格准确 ≥95%、非法拦截 100%、取消 100%。
- [ ] P95 帧时间 ≤33.3 ms，且记录采样方法与构建版本。
- [ ] 普通意图拒绝率总体 ≤10%，任一玩家 ≤20%。

结果填写到 `phase-a-touch-results.csv`，不得把桌面浏览器仿真填入真机列。
