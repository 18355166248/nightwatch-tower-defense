# Phase B 冷凝脉冲可读性回归（2026-09-26）

## 问题与改动

上一版把范围圈画在只保留 0.1 秒玩法时间的弹道上，2× 时约 0.05 秒真实时间，难以辨认。现在把命中范围圈抽成独立反馈通道：保留 0.5 秒玩法时间，2× 时约 0.25 秒真实时间；使用短暂浅色覆盖和淡出的边缘圈，半径直接取战斗事件中的 `slowRadiusCells`。只有确实施加减速才生成，效果结束自行清除，暂停/重开仍由表现层统一管理。伤害、减速结算、塔价与波次均未改动。

塔属性改为显示“范围减速”；冷凝升级成功提示改为“范围减速增强”，机枪则提示火力与射程提升，避免同一“攻击能力提升”误导玩家。

## 验证

- `npm run verify`：63 项规则测试通过。新增测试覆盖：弹道消失后脉冲仍在、0.5 秒到期清除、未减速不伪造脉冲、清理归零；两塔升级文案由纯函数测试。
- `npm run build:web`：Cocos Creator 3.8.8 Web Mobile 构建通过。
- 右侧浏览器 `?build=phase-b-pulse-readable-1519`，约 377×602：1× 第一波和 2× 第二波均看到命中点附近的浅青色范围圈，敌人、路线与顶栏仍可辨；点选冷凝塔时顶栏显示“冷凝塔 Lv1 · 3格 · 范围减速75%”。两波正常清场，控制台 0 error/warning。
- 尝试继续标准推荐构筑时，第五波清场金币为 55，而开波前 52 金、本波收入 +69；检查发现第二座机枪已升至 Lv3，额外成本 24+42=66 金，账目完全吻合。由于存在推荐流程之外的升级，本次浏览器运行不算标准八波回归，也不据此调平衡；当前现场保留供查看。该升级的触发来源未由本次观察确定。
