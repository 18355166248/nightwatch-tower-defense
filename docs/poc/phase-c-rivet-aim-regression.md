# 首关机枪塔炮身摆头回归（2026-09-27）

## 意图与边界

- 只对现有机枪塔分层切图的独立炮身增加轻微瞄准转向，底座、索敌、射程、伤害、寻路、经济与波次逻辑不变。冷凝塔仍使用独立能量芯脉冲，不套用机枪姿态。
- 反馈目标直接来自战斗系统的 `shots` 事件；每塔只留最近一发，持续连射更新目标。短时窗 0.48 秒，末段 0.18 秒平滑回正。3/4 视角原画不适合整圈朝向，所以限制在左右各 38 度，后方目标保持中立；这不是正式的全方向跟踪动画。
- `CombatFeedbackRuntime` 管事件寿命，`TowerAimVisual` 纯函数只算角度，`LayeredTowerRig` 只管分层节点姿态，`PhaseBUnitSpriteView` 做只读绑定。普通暂停冻结反馈时间；教学波间短反馈仍能收尾。

## 转轴修正候选（同日追加）

- 对照 128×128 炮身切图，机械连接轴约在 `(64,112)`，原实现绕画布中心 `(64,64)` 转动，容易出现动态脱座。现在分层塔的几何参数集中在 `LayeredTowerGeometry`；机枪炮身以 `(0.5,0.125)` 为锚点，节点位置做对应反向补偿，保证零角画面不挪位。冷凝能量芯仍使用 `(0.5,0.5)`。
- 后方目标不再夹到左右 38° 伪装成侧向瞄准，保持中立。纯函数测试覆盖两种塔的零角配准、开火偏移、前/后目标角度；所有改动只在表现层。
- 这一修正仍须以**本节后续最新构建**的浏览器回归为准；上文 `phase-c-rivet-aim-1740` 是修正前构建，不能拿它证明锚点改动的实机表现。
