# Phase B 敌人持续减速可读性回归（2026-09-26）

## 问题与改动

- 冷凝命中后，原来只有细青圈；第二波敌人扎堆时，持续 1.2 秒的减速目标不容易从普通敌人中找出。
- 现由战斗快照的 `slowRemainingSeconds` 映射视觉强度：受减速单位持续带轻青色身体色调和四刻度冰环，临近结束逐步淡出。短暂命中闪光仍优先显示，结束即回白色常态。
- Sprite 与 Graphics 灰盒回退共用同一冰环绘制；血条、逻辑位置、减速倍数、伤害和输入均不变。

## 验证

- `npm run verify`：47/47 通过，含强度上下限、半程与结束归零测试。
- `npm run build:web`：Web Mobile 发布构建成功。
- 右侧浏览器 `http://127.0.0.1:4176/?build=slow-readability-0605`，约 377×600：四塔横墙、第一波和第二波可继续；第二波同时出现减速与未减速敌人时，冰环可辨且未遮住血条或路线；第二波清场金币 96、核心 10，控制台 0 error / 0 warning。
- 最终构建 `http://127.0.0.1:4176/?build=slow-readability-final-0611` 已进入首关并复核四塔布阵、路径 16、控制台 0 error / 0 warning；停在点击 ▶ 即可开第一波的状态，供交叉查看。

## 边界

- 浏览器截图只证明部分战斗时刻的视觉阅读性，不证明玩家能准确理解减速时长或战斗策略；灰盒故障注入尚未实机复演。
- 敌人目前仍是静态切图叠加程序姿态，正式跑动/受击/死亡帧、真人体验与 Android 真机验收均未完成。
