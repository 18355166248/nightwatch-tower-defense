# 第一关升级决策闭环 · 2026-09-26

## 范围与实现

- 首关保留机枪/冷凝两种塔，每种只开放一次升级：机枪 24 金、冷凝 32 金。等级属性由 `TowerLevelRules` 统一解析，部署模型负责原子扣费与等级记录，战斗运行时只读取当前等级。升级不改变占格与流场版本；准备态撤销全额退回塔身和升级金，开战检查点可恢复已升级的塔。
- 点已建塔显示对应等级、真实射程及可升级按钮；升级成功后自动收起选塔面板，避免遮挡下一步教学。第一波清场后教学优先提示升级一座机枪，之后继续提示补塔；可跳过教学。Lv2 在战场上有独立暖金外环，缺图时灰盒也可读。
- 本切片只解决“回款后有一次强化抉择”，没有宣称完整三阶升级、重装敌人、末段难度或两塔平衡已完成。
