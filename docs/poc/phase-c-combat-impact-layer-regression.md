# 首关短命中反馈分层复核（2026-09-27）

## 改动范围

原机枪与冷凝命中都使用同一枚浅色圆环，枪口仅有小亮点；高频战斗有伤害但缺少塔种区分。新表现层 `CombatFeedbackView` 从 `PhaseBCanvasRenderer` 抽离弹道、减速脉冲、命中、死亡、奖励及漏怪绘制；`CombatFeedbackRuntime` 只给原有命中事件补充射击塔种、炮塔位置和致命性快照。

- 机枪：枪口短促暖光；普通命中仅两道前向短火花，致命命中五道。冷凝：青色枪口、四向晶芒，原范围减速圈保留。全部用已有短反馈计时衰减，不加 Tween、随机数、模拟停顿或镜头震动。
- 仍通过最大 64 条/通道的现有反馈上限约束密集场景。命中绘制只读取快照，不修改伤害、路径、经济、暂停或重开状态。真正的多帧单位受击/死亡素材仍未制作。
