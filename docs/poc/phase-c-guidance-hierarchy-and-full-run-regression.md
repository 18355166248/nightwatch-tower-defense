# 第一关教学信息层级与最终构建 1× 八波回归

日期：2026-09-27。目标是让初次布防时只保留一处主要动作指令，并确认该调整与上轮波间残影修复共同进入同一个可通关的 Web Mobile 构建。本轮只在右侧浏览器约 390×600 的默认窗口操作，不做 Android 真机测试。

## 实现边界

- `PhaseBHudView` 在引导主提示可见时收起底部重复小字，把主提示由 36 提至 43 设计字号、两行行高调至 50；自由模式、选塔查看与实际战斗仍保留底部帮助行。顶栏事件槽内容为空时不显示文字。
- `NightwatchPocBootstrap` 进入引导时清空旧的初始操作说明；选塔和合法预览的顶栏状态只报告“已选塔”“可建造”和路线变化，具体下一步由中央提示承担。无障碍画布描述在没有状态文案时不留下尾部逗号。
- UI 只消费现有状态与 `FirstLevelExperience` 快照；建塔事务、战斗、敌人参数、回款与按钮热区未改。处理遵循“先让玩家看见下一步，再展开帮助”的游戏 UI/UX 原则；完整 1× 跑测覆盖关卡设计中的教学、压力与结算节奏。

## 工程与右侧浏览器

- `npm run verify`：TypeScript 检查通过，91/91 项规则测试通过；`npm run build:web`：Cocos Creator 3.8.8 Web Mobile 发布构建通过。
- 构建链接：`http://127.0.0.1:4176/?build=phase-c-guidance-hierarchy-final-1319`，没有 `qa=1`。默认入口点“开始布防”后，首屏只由中央两行主提示指向机枪塔和高亮格；顶栏旧的操作长句及底部重复小字不再同时竞争注意。选机枪、点目标格预览、二次确认后为 110 金/1 塔；随后冷凝与两座机枪依次建成 10 金/4 塔/16 格路线，底栏“开始第一波”保持可见且可点击。
- 预览状态顶栏为“可建造 · 路线不变/路线 +2 格”，中央保留“再点同一格确认”。第 1 波清场后，波间升级按钮、升级高亮、下波预告和加固提示在同一窗口可见。未做额外视口覆盖，不能据此声称其他比例已复核。
