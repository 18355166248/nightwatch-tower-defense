# Phase B 炮塔显式出售与波间重构（2026-09-27）

## 问题与改动

- 原首关只允许开局再次点同一座塔全额撤销，缺少可见操作；第一波开始后完全不能出售。这与方案规定的“明确出售按钮、第一波后返还累计投入 70%、只在波间重构路线”不一致。
- 已建塔现在第一次点选只显示射程及并列的升级/撤销（波间为升级/出售）按钮，按钮标出实际返还金币；重复点同一塔仅关闭查看，不会无意卖掉。
- 开局仍全额返还；波间按塔及等级的累计投入乘 `7/10` 向下取整。出售和建造一样更新金币、地图版本及流场；生成/清场战斗期、用户暂停、胜败页均锁定出售。教学清场暂停视作波间，可出售；波间倒计时已经归零并进入下一波时，再来的出售请求拒绝。
- 窄屏两个按钮与触控热区共用布局常量；出售报价只由 `PlacementModel.saleQuote` 生成，HUD、辅助描述和实际扣/返钱不另算。

## 边界

- 本轮浏览器实测开局及第一波波间，不把它写成八波重构策略验收；70% 规则可能改变自由构筑经济，仍需无指导玩家和长局样本。
- 现阶段使用可点击横排按钮完成灰盒操作，尚不是方案中正式美术的环形塔操作；美术完成后需再核查按钮可读性与命中。当前按要求不做 Android 真机测试，Phase B 未通过。
