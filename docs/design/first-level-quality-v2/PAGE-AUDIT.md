## 差距与处理

旧首页、暂停、设置、确认、异常提示和结算沿用平面蓝灰底板，与铜框夜城战斗HUD不一致；部分字号未纳入0.72比例，教程箭头仍指旧塔栏位置。设置按钮在320宽时约30px高，确认和结算按钮也不足44px。

本轮统一为铜框、墨蓝内面、低对比刻线、米白正文；主操作暗青绿、离开操作暗红、禁用灰。正文按同一比例缩小，不能通过放大字体弥补信息层级。面板、文字、命中几何分离：`FirstLevelPanelPainter`共享饰面，`FirstLevelResultPainter`独立结算，原状态机继续拥有恢复/退出规则。

## 原生 / 图片边界与资源规格

- 首页/暂停/设置/确认/异常/结算框体：原生Graphics分层绘制，参考1080×1920；中心锚点，统一等比SHOW_ALL，不导入整页PNG。按钮与标签分离，动态文案不烘焙。
- 战斗HUD、塔栏、检查器：沿用已有5张铜框PNG切片；索引 `slice-manifest.json`、规格 `COCOS-INTEGRATION.md`。
- 首页三张插画：复用真实透明单位资源（机枪/冷凝/发条步兵），显示160×160，中心锚点，不再从概念稿截战场角色。
- 字体：系统PingFang SC及平台回退，不打包未经授权字体；普通文字统一×0.72，暂停/关闭符号单独保留辨识尺寸。
- 原生面板边界与图片铜框的纹理细节仍有差异，不能仅凭同色宣称达到Fieldrunners 2品质。是否接受此方向由用户视觉确认。
