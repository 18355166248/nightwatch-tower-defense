# 战斗 UI 接入记录（2026-10-01）

用户授权：先接入这一版，字体再缩小；这不是首关最终视觉验收。

## 本次范围

- 实际 Cocos 战斗 HUD、底部塔栏、选塔升级/出售面板接入独立饰面。
- 普通文字统一从设计基准的 0.86 降到 0.72（再缩小约 16.3%）；暂停、关闭符号保留辨识尺寸。
- 普通模式使用 SHOW_ALL 整体等比适配，窄长视口允许留边，不裁掉塔栏、不单独放大字体。QA 旧布局保留。
- 图片只承担非交互饰面；文字、金币、波数、血量、等级、伤害、射程与减速来自真实配置/快照。
- 建塔、升级、撤销、波间出售、开波和暂停继续走已有玩法输入链路。
- 普通模式音量/声音入口在暂停设置和首页设置；HUD 顶部右侧改为暂停，不再伪装声音按钮。
- 塔栏和选塔肖像复用当前透明战斗塔素材，不导入概念稿的带地面卡图。

## 模块与资源

- `FirstLevelUiStyle.ts`：统一字号比例及字体。
- `FirstLevelUiGeometry.ts`：设计版操作矩形、关闭热区；渲染与输入共用，不修改 QA 坐标。
- `FirstLevelUiSkinView.ts`：独立饰面/原生文字/资源失败回退/事件字段签名；不持有玩法模型。
- `PhaseBHudView.ts`：普通战斗切到设计版，QA 与未重设计的结算继续复用原视图。
- `scripts/import-quality-ui.cjs`：机械复制五张切图，重复导入保持 UUID。
- 运行时目录：`assets/resources/level-one/ui/quality-v2/`。
- 源图：`art-source/design/first-level-quality-v2/ui-material-board.png`；切图矩形见 `slice-manifest.json`。
- 原图、生成来源与设计稿继续保留；没有生成或扩展新美术家族。

原生边界：动态数值、标题、塔属性、可用/不可用文案、符号和程序回退由 Cocos 绘制；五张框体为图片，透明塔及资源图标复用已有资产。所有饰面都是无文字切片，非整张截图覆盖游戏。

交互尺寸：按 1080×1920 参考画布换算，320px 战场宽时最小操作边长 150×320/1080≈44.44px。字体缩小不缩点击矩形。关闭与升级/出售不重叠。

game-ui-ux 技能影响：将字号与热区分开、整体等比适配、原生 HUD 只在展示字段变化时更新；create-game-assets 技能影响：饰面独立入库、透明塔图复用、失败保留可操作回退。

## 尚未完成的验收

- 战场构图、地图层次、敌群密度、塔三级完整外观、特效仍不是代表设计稿的完整还原。
- 首页、教学、暂停、胜败页没有在这轮统一成 v2 风格。
- 普通 1× 三局八波完整回归仍未执行，不能用本次 UI 冒烟检查替代。
- 五张框体 RGBA 解码约 4,096,864 bytes；整局 GPU 纹理预算尚未达标。本轮不修改预算、不宣称性能通过。
- Cocos 以 Sprite 颜色降低框体亮度；未完全复刻设计网页的饱和度滤镜，也未重新绘制更薄的框。
- SHOW_ALL 在短矮视口会受高度约束而比给定屏幕宽度更窄；44px 是战场本身宽度至少 320px 时的保证，不是任意窗口尺寸下的保证。
- 视觉是否满足阶段标准仍由用户确认。本次未提交、未推送。
