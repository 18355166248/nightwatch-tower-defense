## 后台事件检查

- 本地 Cocos Creator 3.8.8 `pal/system-info/web/system-info.ts` 已监听 document visibilitychange 和 window pagehide/pageshow；引擎向 Game EVENT_HIDE/SHOW 转发。
- 项目 onLoad 注册、onDestroy 移除 Game EVENT_HIDE/SHOW。hide 暂停战斗、取消手势、挂起声音；show 解除后台阻塞，但仍等待玩家点继续。
- 项目 window/canvas blur 只取消手势，刻意不把一般失焦等同后台。没有证据支持将 blur 改成后台暂停，或重复添加页面监听器。
- 右侧普通首波、1×：调用浏览器面板隐藏前，document.visibilityState=visible、战斗时间 0.216667；隐藏后仍 visible、document.hidden=false、战斗时间 0.233333、lifecycleRecovery=false。随后恢复面板显示。
- 结论：隐藏面板不是页面真正后台，此操作没有触发实际生命周期；不能以 QA 快捷键或此操作宣称真实后台恢复通过。
- 已请求用户手动让页面真正进入后台并回来，检查恢复提示、时间冻结及需要手动继续。尚未收到结果。
