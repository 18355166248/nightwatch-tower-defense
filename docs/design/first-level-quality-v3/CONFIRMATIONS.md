# 确认弹窗接入与对照 · 2026-10-02

用户明确回复“按新稿接入”。本批只实现获批的重新部署与返回首页两张弹窗，不代表全页面重设计完成，不代表用户已认可最终运行效果。

## 实现边界

- `FirstLevelConfirmationPresentation` 统一管理可编辑文案、语义动作和390×844稿件几何；文字、饰面与输入共用同一缩放，不使用旧的0.72字号系数。
- 首页确认的主按钮为取消，次按钮为离开；输入按 `cancel/home/restart` 分发，不依赖旧按钮下标。
- `FirstLevelPageSkinView` 复用本地无字素材，允许单页指定九宫格显示边框。未添加运行图片、联网依赖或整页烘焙。
- 图标、标题、用途眉题、战况、三行正文、两按钮、辅助说明均由原生节点组合。局内波次／核心取真实状态。
- 正文分隔线为原生几何，在饰面上方绘制；实心细线避免低倍率描边过淡。关键逻辑有中文注释。
