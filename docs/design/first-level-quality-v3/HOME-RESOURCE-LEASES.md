## 修改边界

首页原本完整不透明地盖住战场，但仍加载/持有640×1137的背景，开销2,910,720字节。`PhaseBBackdropView`复用`VisibleAsyncAsset`，仅非首页期间加载并持有背景；隐藏时先清精灵引用，再归还独占租约。加载结果包含资源路径，避免迟到回调把旧路径回填当前页面。销毁与快速离开沿用租约代际保护；失败保持同尺寸档的候选回退，全部失败才用已有程序化战场。暂停、确认、结算仍显示战场，不能因此释放背景。角色、共用饰面和全局缓存未清理。

`FirstLevelUiSkinView`复用`VisibleLabelSlots`：首页不创建战斗文字；返回首页或结算时销毁文字节点；可见战斗快照只保留实际用到的标签槽。重现仍用原字体、字号、行高、90px高度、锚点、原CLAMP宽度与输入几何。上一轮宽度候选依旧只通过显式参数启用，未默认接入。新增关键路径有中文注释。

## 实测与限制

1280×720浏览器内的竖屏游戏，同一存档、普通非QA自由布防、1×。先测量后修改，不修改8MiB预算，也不改B图片像素。

| 首页场景 | 总GFX纹理字节 | 资源缓存字节 |
| --- | ---: | ---: |
| 旧版冷启动首页 | 11,966,492 | 8,107,232 |
| 仅背景租约的冷启动首页 | 9,055,772 | 5,196,512 |
| 联合隐藏文字释放的冷启动首页 | 8,313,792 | 5,196,512 |
| 联合方案首波暂停后返回首页 | 9,362,368 | 5,196,512 |

冷启动首页减少3,652,700字节（约3.48MiB），总GFX约7.93MiB，仅这个场景低于8MiB。返回首页Label2,041,520、隐藏Label40与冷启动相同，但动态图集从1张变2张512²，多1,048,576字节；返回首页总GFX约8.93MiB，**仍超预算**，不能宣称首页往返或全阶段达标。

背景租约的中间版本返回首页隐藏Label504,052、总GFX10,608,340，是第二项文字修复的实际依据；不能只根据`destroy()`推测已释放。

进入无塔战场后，B背景路径恢复，缓存6,732,032，总GFX9,430,672、隐藏Label40；原来隐藏空槽少20字节，不影响画面。两塔70金、14格路线、首波暂停总GFX11,111,104，仍超8MiB；暂停保留背景，未把本应显示的资源卸载。

首屏图片33请求、响应体2,102,128、ResourceTiming.transferSize2,112,028、unknown0；原来34请求、响应体2,887,390、transferSize2,897,590。进入战场后累计恢复34请求，但已封存的首屏统计不重写。transferSize不是完整网络抓包，不代表全部JS/音频流量。
