## 修改与边界

首页插画只由 `FirstLevelHomeArtView` 使用。离开首页先清除 SpriteFrame，再归还 addRef/decRef 租约；返回重新加载原图。两种炮塔贴图有战场消费者，不强制释放共享缓存。依据本机 Cocos Creator 3.8.8 的 Asset 与 ReleaseManager 实现：decRef 自动释放发生在下一 tick，采样诊断也有延迟，不能以点击后即时读数判定失败。

异步资源所有权抽离为纯逻辑 `VisibleAsyncAsset`，加载/引用计数/绘制通过适配函数注入。世代标识隔离旧回调；隐藏与节点销毁时归还当前租约；隐藏期间迟到的结果归还且不发布。没有改美术、尺寸、编码、阈值或预算报告口径。

## 实测

| 状态 | 修改前缓存字节 | 修改后缓存字节 |
| --- | ---: | ---: |
| 首页 | 13,643,136 | 13,643,136 |
| 离开首页、初始布防（采样稳定后） | 13,643,136 | 12,267,936 |
| 第二次开局、建两类塔并暂停 | 未另测 | 12,267,936 |

减少 1,375,200 字节，恰等于 764×450×4 的首页插画。返回首页画面重新加载成功、art 失败0，缓存回到13,643,136；第二次离开后恢复12,267,936，没有这一资源的累计驻留。两次开局均手动建造机枪/冷凝，140→110→70，路径12→14，普通1×开波→暂停→返回确认正常。

初始布防前后截图均769×596，原始RGB通道只有84处数值不同（总1,374,972通道），不称完全像素相等；未改变布局与资产。临时证据：`/private/tmp/nightwatch-confirmation-fidelity-aeMb8G/resource-before-battle.jpg`、`resource-after-battle.jpg`、`resource-home-return.jpg`。浏览器截图不入 Git。
