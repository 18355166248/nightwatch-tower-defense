这版解决什么

塔名与等级 → 当前属性 → 下一阶提升 → 操作，形成固定阅读顺序。撤销弱化，升级作为主操作；两者保留独立热区。

没有用大字号撑层级：标题14px，属性数值13px，正文11px，注释10px。窄宽连同装饰等比缩小，按钮54px参考高度在320宽下仍为44.3px。

金币不足直接报告差额；满级不显示虚假的下一阶；战斗禁售保留原因，避免左右操作跳位。

建造有效和无效使用同一面板，不靠红绿颜色独自表达结果。最终状态由真实放置校验给出，不能只按金币判定。

面板仅在建造预览或选塔时临时出现。建造、升级、撤销或出售成功后收起，用短提示反馈；取消或点击空白战场也收起。关闭后不留空槽，不挤小战场。失败时保留原因，允许取消。

审查、规格与接入边界

稿件已确认并接入，实际游戏最终视觉待用户验收。不包含横屏、外围系统或新增功能。原生标签及热区在 Cocos 中独立实现，图片仅负责无字材质与塔肖像。点选落点被面板遮挡时可用确认建造按钮；拖放仍松手提交。
